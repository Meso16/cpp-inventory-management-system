# C++ Inventory Management System
## Overview 
An individual C++ project developed as part of my coursework at Aptech Computer Education

## Features 
- Add, view, update, and remove inventory records
- Search inventory by item ID or item name
- Save and load inventory records using a TSV file
- Track item quantities and prices
- Validate user input and prevent duplicate item IDs
- Confirm deletion before removing records

## Technologies
  - C++
  - File handling with input/output streams
  - Standard Template Library (STL)

## Data Storage
Inventory records are stored in inventory.tsv. The application loads saved records when it starts and writes changes to the file when inventory items are added, updated or removed.

## How to Run
Compile inventory.cpp with a C++ compiler that supports C++17 or later, then run the resulting executable. The program creates or uses inventory.tsv in its working directory when saving inventory data.
